# Contributing

Install from source with `python -m pip install -e .`, then run
`python -m unittest discover -s tests -v`.

Please open an issue describing the input, expected behavior, actual behavior,
Python version, and a small reproducible example. Keep private data and keys
out of examples. Add regression tests for changed behavior. Document assumptions
and benchmark provenance. Real-world evaluations and integration reports are welcome.

This project was initially developed with AI assistance. Maintainers review
changes and remain responsible for behavior, tests, and reported results.
